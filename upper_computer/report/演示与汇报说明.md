# OpenArm 上位机课程汇报与演示说明

## 推荐汇报顺序

### 一、先演示仿真上位机

1. 双击 `..\run_mujoco_vision_bridge.bat`，等待 MuJoCo Viewer 和 `ws://127.0.0.1:8765` 启动。
2. 双击 `..\run_mujoco_upper_computer.bat`。
3. 指出上位机正在持续接收 640×480、5 FPS 虚拟相机画面，并显示检测框、类别、置信度和 `base_link` 坐标。
4. 点击“确认执行”，展示规划、执行、成功/失败状态以及机械臂靠近、夹取、抬升、搬运和放置的中间画面。
5. 展示安全限制：只有目标匹配已验证右臂示教点才允许执行；其他位置被拒绝。
6. 关闭 Viewer 后说明上位机能够显示断线并自动重连。

### 二、再演示真机侧上位机

1. 视觉同学程序已在本机或局域网启动时，双击 `..\run_vision_monitor.bat`。
2. 展示 RealSense/YOLO JPEG、类别、像素中心、深度、心跳、掉线重连和超时提示。
3. 明确指出执行按钮被锁定：当前视觉消息缺少相机内参、相机到 `base_link` 外参、基座三维坐标、检测框、置信度和时间戳，不能安全转换为机械臂目标。
4. 双击 `..\scan_serial_ports.bat`，展示端口只读扫描。当前 COM3～COM6 均为蓝牙虚拟串口，没有 USB-UART。
5. 说明 USART10 24 字节协议编解码、抗分片/噪声解析和 J1 只读监视工具已经完成，但不主动发送控制帧。

若现场没有 D435i 或视觉服务，真机侧演示应改为“接口与安全闭锁演示”：展示视觉组现有消息格式、上位机只观察界面、串口扫描结果和协议离线解析，不声称已经驱动真机。

## 未完成真机部署的主要原因

- 视觉侧输出的 `x/y` 是像素、`z` 才是深度，缺少 `base_link` 三维坐标与手眼标定。
- 缺 D435i 实测内参、相机序列号、相机安装位姿、标定误差和最终类别权重。
- STM32 固件 USART10 当前只回传 J1；收到的 `pc_data` 没有接入电机执行。
- 24 字节命令帧没有关节编号，无法表达 J1～J7 独立命令；还缺 ACK、CRC、序号、看门狗、回零、取消、清故障和急停语义。
- 尚未确认 MuJoCo/URDF 关节与真机 J1～J7 的机械零位、符号和偏置映射。
- 未插入并确认 3.3V TTL USB-UART 的型号、接线和实际 COM 端口；硬急停和断电回路也未验收。

## 已验证证据

- 原 V18.3 视觉抓取报告：左右任务 `place_success = 2/2`。
- 实时推流回归：完整抓放执行区间 6.06 秒收到 51 张不同中间帧。
- `home` 短动作：2.11 秒收到 9 张不同帧，状态 `PLANNING → SUCCEEDED`。
- 汇报交付前完整桥接回归：`PLANNING → EXECUTING → SUCCEEDED`，右臂抓取/放置 `1/1` 成功，抬升 0.1003 m，放置 XY 误差 0.0244 m；结果保存在项目根目录 `outputs/upper_computer_mujoco_bridge/`。
- 上位机自动测试：28 项全部通过。

## 汇报口径

结论应表述为：仿真上位机已经形成可演示的软件闭环；真机侧完成了视觉接入、协议审查、只读工具和安全闭锁，但由于跨组接口、标定、固件闭环及硬件安全条件不完整，没有冒险开放真实电机写控制。
